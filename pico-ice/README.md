# VARIOUS GATEWARES FOR THE PICO-ICE

A number of different pico-ice gatewares will be hosted here.

**BootLoader** This directory holds a bootloader bitstream, with a choice
of 3 different images listed below.  It also has the ``compile`` command which
you can use to build your own custom bootloader.

**Mecrisp** Ice J1a** This is the basic 16 bit Mecrisp Ice. It inlucludes
the warmboot option to load a different gateware. 

**Blinky**: A blinky is useful to reset the FPGA, and make sure that
  you are downloadinga new program.

**Echo Server** An echo server is great for debugging the uart.  When
  plugged int blinks slowly, when you type a letter, it blinks
  quickly.
